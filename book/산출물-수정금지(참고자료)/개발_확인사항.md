# 전화영어 교재 뷰어 — 개발 확인사항

화면 · 코드 규칙은 `README.md`. 이 문서는 개발에서 연결하거나 결정해야 할 항목만 정리한다.

## 1. 먼저 볼 파일

| 파일 | 용도 |
|---|---|
| `산출물-수정금지(참고자료)/book-magazine-en.html` · `-zh` · `-ja` | 언어별 완성 화면(단일 파일). 더블클릭으로 열림 |
| `magazine.html` | 나눠진 파일(css · js · images) 조립본 |
| `data/lesson-01.json` | 레슨 데이터 예시 = API 응답 형식 |
| `README.md` | 폴더 · 코드 · 동작 · 이미지 규칙 |

## 2. 언어별 컬러

| 언어 | `lang` 값 | 컬러 | 메인 색 | 그라데이션 |
|---|---|---|---|---|
| 영어 | `en` (기본) | purple | `#6d68e4` | `#2373f4` → `#915dd2` → `#c04695` |
| 중국어 | `zh` | coral | `#f06445` | `#973479` → `#f06445` → `#dce8a5` |
| 일본어 | `ja` | green | `#0faa78` | `#00a283` → `#5ed83d` → `#b5ee62` |

- 정의 위치: `css/tokens.css` 맨 아래 `html[data-lang="zh"]` · `html[data-lang="ja"]`. 영어는 `:root` 기본값.
- 적용 방법 (`<html data-lang>`이 있으면 그 값이 우선):
  1. **권장** — 서버가 HTML을 내려줄 때 `<html lang="ko" data-lang="zh">`. 첫 화면부터 해당 컬러로 그려진다.
  2. 데이터 `course.lang` — `<html>`에 `data-lang`이 없을 때만 `magazine.js` 시작 시 적용. 스크립트 실행 전 잠깐 기본색이 보일 수 있다.
  3. 앱에서 `Book.set("lang", "ja")` 또는 `postMessage({ type: "book", key: "lang", value: "ja" })`.
- `html lang="ko"`는 화면 UI 언어(한국어)라 그대로 둔다. 학습 언어는 `data-lang`.
- 언어가 추가되면 `tokens.css`에 `html[data-lang="xx"]` 블록 하나만 추가한다(`--brand-*` 6개).

## 3. 연결 · 구현 필요

| 항목 | 현재 | 위치 | 할 일 |
|---|---|---|---|
| 레슨 데이터 | `data/lesson-01.json`을 빌드 때 `window.BOOK_DATA`로 넣음 | `magazine.src.html` · `core.js` | API 응답(같은 형식)을 `core.js`보다 먼저 `window.BOOK_DATA`에 넣는다 |
| 듣기(음성) | 1.8초 재생 표시만 함 | `js/parts.js` `play()` | 문장별 음성 URL을 데이터에 추가하고 실제 재생 · 종료 시점에 `is-playing`을 켜고 끈다 |
| 학습 완료 | 마지막 파트의 ✓ 버튼은 아이콘만 바뀌고 동작 없음 | `js/magazine.js` `go()` · `#bookNext` | 완료 처리(진도 저장 · 다음 레슨 · 앱 화면 복귀 등) 정의 후 연결 |
| 레슨 목차 상태 | 현재 레슨만 '학습 중', 나머지 '예정' 고정 | `js/magazine.js` 표지 | 완료 · 진행 · 예정 상태와 다른 레슨으로 이동을 데이터로 받을지 결정 |
| 강사 계정 | HTML에 `data-teacher` 데모로 켜 둠 | `magazine.src.html` `.book` | 앱 로그인 정보로 강사일 때만 `data-teacher`(또는 `Book.set("teacher", true)`) |
| 프린트 | `window.print()` | `js/magazine.js` `#bookPrintBtn` | WebView에서 동작하지 않으면 앱 네이티브 인쇄로 연결 |
| 뒤로가기(안드로이드) | 웹 안에서만 닫힘(X · Esc) | 표지 `#bookCover` · 파트 목록 `#bookPartlist` · 크게 보기 `#bookViewer` | 열려 있는 레이어부터 닫고, 없을 때만 화면 종료. 앱에서 처리 |
| 웹폰트 | CDN(jsdelivr Pretendard, Google Fonts Plus Jakarta Sans) | `css/tokens.css` `@import` | 오프라인 · 외부망 차단 환경이면 폰트 파일을 앱/서버에 두고 경로 교체 |
| 이미지 | `images/`의 사진은 임시(원본 크기) | `images/lesson/` · `images/content/` | 실제 사진은 README 4장 크기로 교체. 서버 경로가 다르면 `core.js` `Book.IMAGE_DIR`만 수정 |
| 레슨 사진 개수 | `Book.PHOTO.count = 8` | `js/core.js` | 실제 `images/lesson/` 사진 수에 맞춘다 |

## 4. 바꾸면 안 되는 것

- 보기 설정(가이드 · 번역 · 강사 가이드)은 켜면 파트를 넘겨도 유지되고, 사용자가 직접 끌 때만 꺼진다. 파트 이동 시 초기화하지 않는다.
- 파일 로드 순서: CSS `tokens → base → components → magazine → parts`, JS `core → parts → magazine`.
- 레슨 사진은 CSS 변수에 상대 경로로 넣지 않는다(`css/` 기준으로 풀림). `core.js`의 `applyPhoto()`를 거친다.
- 색 · 글자 크기는 `tokens.css` 변수로만 쓴다.

## 5. 빌드

```
pip install pillow
python3 build.py
```

- `inc/ css/ js/ data/ magazine.src.html`을 고친 뒤 실행 → `magazine.html`, 단일 파일 3종 재생성
- 만들어진 파일(`magazine.html`, `산출물-수정금지(참고자료)/*.html`)은 직접 고치지 않는다
